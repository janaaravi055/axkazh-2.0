# Malai 2.0 — Smart Fraud Alert System

## Main flow
Login → Dashboard → Chatbot → Detection → Alert → User Information → Case ID → Police Inform → Download / Export / Share → Protection Flow

## Routes
/
 /dashboard
 /chatbot
 /detection
 /checklist
 /userinfo
 /police
 /protection-flow

## Run
npm install
npm run dev

## Production verification
npm run build

The Protection Flow page uses the supplied prototype image as the visual reference and adds interactive hotspots plus a coded workflow below it. Detection, storage and reporting are demo-only and do not submit anything to real authorities.
